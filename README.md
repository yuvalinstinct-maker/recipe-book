# ספר המתכונים שלנו

אתר סטטי פשוט (בלי תלויות) עם המתכונים שלנו, בעברית RTL ומותאם לנייד.

## מבנה

- `index.html` - שלד הדף
- `styles.css` - עיצוב
- `app.js` - תצוגה, חיפוש, תגיות והכפלת כמויות
- `recipes.js` - כאן נמצאים כל המתכונים

## איך מוסיפים מתכון

1. פותחים את `recipes.js`.
2. מעתיקים את האובייקט של מתכון קיים, מדביקים אחרי פסיק בסוף הרשימה ומעדכנים:
   - `id` - מזהה ייחודי באנגלית (מופיע בכתובת)
   - `title`, `yield`, `tags`, `source`, `added`
   - `nutrition` - ערכים למנה/יחידה + הערה (אם הערכים לא אומתו, כותבים זאת ב-`note`)
   - `groups` - קבוצות מצרכים; לכל מצרך `qty` (מספר, להכפלה אוטומטית), `unit`, `name`
   - `steps` - שלבי הכנה
3. שומרים ודוחפים ל-git. זהו.

## הרצה מקומית

פותחים את `index.html` בדפדפן, או: `python3 -m http.server` וגולשים ל-localhost:8000.
